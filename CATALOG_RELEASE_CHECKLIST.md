# Tonight 1.6.6 / каталог 1.0.0 — проверка перед публикацией

Состояние на 10.10.2026: **оба релиза опубликованы, полная онлайн-установка
проверена настоящим production EXE без токена**.
Подтверждение автора о проверке прав разрешает подготовить изображения,
но не заменяет отдельное подтверждение публикации. Лицензия Apache-2.0
распространяется на код, не на внешние изображения или данные.

## Проверенные критерии

| Требование | Доказательство |
| --- | --- |
| Отдельные обновления приложения и каталога | Раздел «Каталог», независимые API/менеджеры и версии; browser smoke |
| Понятная сводка и дата | Реальный пакет: 649 карточек, 644 локальных постера, 571 ссылка на трейлер, 568 с обоими; версия 1.0.0/date |

| Обезличенный формат | JSON-проекция публичных полей, 1287 очищенных изображений; нет SQLite или исполняемых файлов |
| Источник, размер, SHA, ZIP, версия | Unit/integration tests и fresh frozen hash/incompatible smoke |
| Личные изменения и стабильные ссылки | Проверены истории, оценки, списки, вкусы, настройки, собственные описания и FK |
| Безопасные media paths/no overwrite | ZIP allowlist, path/link tests, JPEG/PNG/WebP и preservation smoke |
| Snapshot и восстановление | Реальное аварийное завершение до/после commit, restart production EXE; backup и journal checks |
| Ошибки не блокируют вечер | Source/frozen browser smoke сети/recovery; фиксированные безопасные сообщения |

| Полная регрессия | 375 pytest passed; node --check frontend/app.js; git diff --check |
| Новая переносимая сборка | CRC/allowlist, пустые personal tables/FK и исключение локальных credentials |
| Переход со старой версии | Установленный helper 1.6.5 успешно обновляет и перезапускает свежую 1.6.6 без потери данных |

отключение питания. Ссылки на трейлеры не означают, что видео сейчас доступно.
Ни сами фильмы, ни видео трейлеров в пакет не входят.
