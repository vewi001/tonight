# Tonight 🍿

**Меньше выбирать. Больше смотреть.**

Tonight — бесплатный локальный помощник выбора фильма одному или вместе.
Он учитывает настроение, ограничения и оценки знакомых фильмов, предлагает
варианты и объясняет выбор. История и предпочтения хранятся на вашем компьютере.

## Начать смотреть

1. Распакуйте архив и откройте `Tonight.exe`. Устанавливать Python не нужно.
2. Нажмите «По знакомым фильмам», выберите профиль и условия вечера.
3. Оцените **уже просмотренные** фильмы. Для незнакомых нажмите «Не смотрел(а)».
4. При совместном выборе второй зритель отвечает в своём профиле.
5. Выберите фильм из общей подборки. После просмотра оценку можно оставить
   сразу или позже в истории.

Для второго устройства откройте «Подключить телефон» и используйте адрес
или QR-код. Телефон и компьютер должны находиться в одной домашней сети;
для входа нужен код Tonight. Приложение должно оставаться запущенным на ПК.

Tonight помогает выбрать фильм. Встроенного видеоплеера нет, сами фильмы
в сборку не входят.

## Способы выбора

Основной подбор «По знакомым фильмам» учитывает ответы обоих зрителей.
В разделе «Все способы выбора» доступны ещё четыре сценария:

- **По настроению** — настроение, время, компания и фильтры; до пяти вариантов.
- **По описанию** — запрос на русском, например «Детектив без ужасов до двух
  часов» или «Похожее на Интерстеллар». Найденные условия можно изменить.
- **Случайный фильм** — умный выбор, полная неожиданность или фильм из «На потом».
- **Листать карточки** — «Интересно», «Не интересно» и «Уже смотрел» с отменой
  последнего действия. Доступны кнопки, свайпы и стрелки клавиатуры; `Z` отменяет.

Поиск по названию находится в разделе «Найти фильм». Подробности поиска по
описанию и его ограничения — в [SMART_SEARCH.md](SMART_SEARCH.md).

Tonight IQ использует оценки и реакции для персональных рекомендаций.
В «Наш вкус» можно исправить выводы или сбросить обучение. История просмотров
и общий список «На потом» доступны отдельно. Интерес к фильму, сохранение,
выбор на вечер и факт просмотра — разные действия.

Ограничения по времени, годам и стоп-жанрам применяются строго. Настроение
оценивается по жанрам, описаниям и отметкам каталога; оно не гарантирует
определённого эмоционального впечатления.

## Каталог и обновления

Полная Windows-сборка включает локальный каталог и постеры. В поставке 1.13.2
671 запись, из них 532 фильма с подтверждённым русским названием и состоявшимся
кинопрокатом. Неподтверждённые записи сохраняются, но не предлагаются к просмотру.

В «Каталог и обновления» можно загрузить готовый каталог или добавить 20, 50
либо 100 фильмов с постерами. Отдельный ключ приложения уже включён; личный
TMDB-токен не обязателен. Загрузка с телефона выполняется на основном ПК.
Для выбора по сохранённому каталогу интернет не нужен. Загрузка новых данных,
обновления программы и трейлеры требуют соединения.

Программа и каталог обновляются отдельно. Обновление приложения сохраняет
историю, оценки, настройки и изображения; при обрыве доступна докачка.
Перед установкой проверяются размер, SHA-256 и содержимое архива.

Для ручного обновления остановите Tonight, запустите `Обновить Tonight.exe`
и выберите `Tonight-update-<версия>.zip`. Распаковывать этот ZIP не нужно.
Обновитель сохраняет резервную копию и предыдущую версию программы.
Кнопка «Вернуть прошлую версию» возвращает файлы приложения; восстановление
базы выполняется отдельно из резервной копии.

Настройка зеркала и публикация пакетов описаны в [MIRROR_SETUP.md](MIRROR_SETUP.md).

## Данные и приватность

Личные данные хранятся рядом с программой:

| Путь | Содержимое |
| --- | --- |
| `data/tonight.db` | Каталог, профили, история, реакции, оценки и настройки |
| `data/posters/`, `data/backdrops/` | Загруженные изображения |
| `data/art/` | Запасные обложки |
| `data/backups/` | Резервные копии базы |
| `.env` | Локальная конфигурация |

В «Наш вкус» на основном компьютере можно скачать данные, восстановить их
из файла или удалить личную информацию. Экспорт базы не включает изображения.
Для резервной копии без экспорта запустите `backup.bat`.

Регистрация, реклама и скрытая телеметрия отсутствуют. Вкусы, история и оценки
не передаются во внешние сервисы. Сетевые обращения и состав сохраняемых
данных описаны в [PRIVACY.md](PRIVACY.md).

## Запуск из исходников

На основном компьютере нужен Python 3.11 или новее. Запустите `start.bat`:
он создаст `.venv`, установит зависимости и откроет браузер. Ручной запуск:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py
```

Интерфейс написан на HTML, CSS и JavaScript; Node.js и сборка фронтенда для
запуска не требуются. Сервер использует FastAPI и SQLite. По умолчанию приложение
открывается по [http://localhost:8000](http://localhost:8000); если порт занят,
фактический адрес будет указан при запуске.

Исходники содержат 72 стартовые записи, из которых 20 доступны без загрузок.
Полный каталог и постеры распространяются отдельно от исходного кода.
Их можно получить через «Каталог и обновления».

### Постеры и настройка каталога

Общий ключ в `app/tmdb-public.json` позволяет загружать фильмы без ручной
настройки. Свой `TMDB_READ_TOKEN` в окружении или `.env` имеет приоритет.
Для дополнительной настройки скопируйте `.env.example` в `.env`.

Скрипты ручного импорта используют личный токен. Например, загрузка постеров
для стартового каталога:

```powershell
$env:TMDB_READ_TOKEN="ВАШ_READ_ACCESS_TOKEN"
.\.venv\Scripts\python.exe scripts\enrich_starter_catalog.py
```

Импорт более крупного каталога с изображениями:

```powershell
.\.venv\Scripts\python.exe scripts\import_tmdb.py --list smart --pages 25 --images
```

### Необязательная Ollama

Основной подбор работает без Ollama. При её наличии локальная модель может
уточнить порядок уже отобранных фильмов и объяснения. Она не добавляет фильмы
и не служит источником метаданных; неверный ответ возвращает обычный подбор.

```powershell
ollama pull qwen3:8b
```

По умолчанию используются `OLLAMA_URL=http://127.0.0.1:11434` и
`OLLAMA_MODEL=qwen3:8b`. Другую установленную модель можно указать в `.env`.
Ollama должна оставаться доступной только на основном компьютере.

### Домашняя сеть

Разрешите доступ Tonight или Python только для частных сетей в Windows Firewall.
Для телефона используйте адрес из окна приложения, а не `localhost`.
Не публикуйте порт приложения в интернете. Резервные копии, восстановление
и полное удаление данных доступны только на основном ПК.

Правила доступа для локальных инструментов — в [LOCAL_API.md](LOCAL_API.md).
