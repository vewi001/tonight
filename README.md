# Tonight 🍿

Tonight — домашнее local-first приложение для совместного выбора фильма. Каждый зритель независимо выбирает настроение, ограничения и оценивает 20 фильмов. Затем Tonight ищет не «средний рейтинг», а справедливый совместный вариант: фильм, который не должен испортить вечер ни одному из вас.

Никаких подписок, облачного AI, внешней аналитики, аккаунтов или отправки вкусов наружу. База, история, рекомендатор, локальная сводка использования и Ollama находятся на основном компьютере. Второму зрителю нужен только браузер в той же домашней сети.

> **Готовая версия для Windows:** распакуйте переносимую папку и откройте
> `Tonight.exe`. В ней уже есть приложение и локальный каталог; отдельная
> установка Python не нужна.

Tonight — самостоятельный продукт для домашних киновечеров. Исходный код и
служебные материалы хранятся в закрытом рабочем репозитории команды Tonight и
не являются способом распространения приложения.

TMDB-токен не входит в исходный код, Git-коммиты или публичные релизы. Он
остаётся только в локальном файле `.env` владельца. Готовый релиз с поставляемым
каталогом, постерами и ссылками на трейлеры не требует от пользователя своего
токена.

## Как это устроено

```text
Второе устройство ─┐
                   ├── Tonight / FastAPI на основном ПК ── SQLite
Основной браузер  ─┘                      │
                                         ├── локальный рекомендатор
                                         └── Ollama 127.0.0.1:11434 (необязательно)
```

Браузер обращается только к `/api/...` и `/ws/...` на сервере Tonight. Ollama не публикуется в сеть и никогда не вызывается из браузера.

## Быстрый запуск на Windows

### Переносимая папка — рекомендуемый вариант

Если рядом есть папка `Portable Tonight`, дважды нажмите `Tonight.exe`. Всё нужное
для работы уже внутри: отдельный Python устанавливать не нужно, а маленькое окно
Tonight позволяет открыть приложение в браузере или остановить его после вечера.

В папку уже включён большой локальный каталог с постерами и ссылками на трейлеры.
При первом старте он копируется в `data/` и занимает немного времени; история,
оценки и настройки пары в этот каталог не попадают.

Ваши история, настройки и каталог сохраняются рядом с программой в `data/`; файл
`.env` также остаётся рядом с ней. Чтобы обновить Tonight, сначала остановите его
в маленьком окне, откройте `Обновить Tonight.exe`, выберите файл
`Tonight-update-<версия>.zip` из папки `Updates`. Перед заменой программа создаёт
резервную копию в `data/backups/`. Кнопка «Вернуть прошлую версию» возвращает
прежние файлы приложения, не удаляя личные данные.

Переносимая версия не ищет и не скачивает обновления сама: используйте только
полученный файл обновления. Если после новой версии понадобится восстановить
старую базу, выберите страховочную копию в интерфейсе Tonight — автоматический
откат базы намеренно не выполняется, чтобы не потерять новые оценки и историю.

### Запуск из исходной папки

На основном компьютере нужен Python 3.11 или новее. При установке Python отметьте **Add Python to PATH**.

1. Дважды нажмите `start.bat`.
2. При первом запуске зависимости установятся в локальную папку `.venv`.
3. Основной браузер откроется автоматически.
4. В терминале появится адрес для второго устройства и QR-код, например `http://192.168.1.42:8000`.
5. Второй зритель открывает этот адрес в браузере. На втором устройстве не нужны Python, Node.js, Ollama или установка приложения.

Если браузер не открылся, перейдите на [http://localhost:8000](http://localhost:8000).

### Windows Firewall

При первом запуске Windows может спросить разрешение на сетевой доступ Python. Разрешите доступ только для **Private networks / Частные сети**.

Не включайте Public networks, не настраивайте port forwarding и не публикуйте порт 8000 в интернете. Tonight рассчитан на доверенную домашнюю сеть.

Телефон передаёт код текущего вечера не только при входе, но и с последующими
личными запросами. До ввода кода LAN-устройство не получает участников,
предпочтения, историю или рекомендации. Резервные копии и полное удаление данных
доступны только через `localhost` на основном компьютере.

## Ollama — необязательное локальное улучшение

Без Ollama приложение полностью работает: жёсткие фильтры, fairness penalty, история и совместный выбор рассчитываются детерминированно.

Чтобы добавить локальное переранжирование и более естественные объяснения:

1. Установите Ollama на основной компьютер с [ollama.com](https://ollama.com/).
2. Скачайте модель:

```powershell
ollama pull qwen3:8b
```

3. Перезапустите `start.bat`.

По умолчанию используются:

```text
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:8b
```

Чтобы выбрать другую установленную модель, скопируйте `.env.example` в `.env` и измените строку `OLLAMA_MODEL`. Не задавайте `OLLAMA_HOST=0.0.0.0`: наружу должен быть доступен только Tonight.

## Каталог фильмов

Первый запуск создаёт локальный starter-каталог из более чем 70 реальных фильмов с публичными фактами и оригинальными короткими описаниями. Пока для конкретного фильма нет отдельного постера, Tonight показывает одну из трёх оригинальных cinematic-обложек по жанру (sci-fi, mystery/thriller или тёплый драмеди-визуал). Они лежат локально, не требуют интернета и не являются копиями постеров фильмов. SVG-placeholder остаётся только запасным вариантом.

### Настоящие постеры для starter-каталога

Для текущей личной некоммерческой версии можно один раз скачать настоящие постеры и фоны в локальный кэш:

```powershell
$env:TMDB_READ_TOKEN="ВАШ_READ_ACCESS_TOKEN"
.\.venv\Scripts\python.exe scripts\enrich_starter_catalog.py
```

Скрипт ищет каждый starter-фильм по оригинальному названию и году, проверяет совпадение, сохраняет изображения в `data/posters` и `data/backdrops`, а runtime после этого больше не зависит от внешнего image server.

Большой каталог автоматически пополняется через бесплатный developer API [TMDB](https://developer.themoviedb.org/). Понадобится бесплатный Read Access Token из настроек аккаунта TMDB. Сеть нужна только для фонового обновления: выбор фильмов, история и оценки работают по локальной базе.

### Автоматическое обновление каталога

Не нужно вручную добавлять фильмы, жанры или описания. Один раз создайте файл `.env` рядом с `start.bat`, скопировав в него строки из `.env.example`, и вставьте свой бесплатный TMDB Read Access Token:

```text
TMDB_READ_TOKEN=ваш_токен
CATALOG_AUTO_UPDATE=1
CATALOG_REFRESH_DAYS=7
CATALOG_PAGES=25
CATALOG_LIST=smart
CATALOG_MIN_VOTES=50
```

После этого Tonight при запуске в фоне обновляет локальную SQLite-базу один раз в новую календарную неделю. Умная лента равномерно объединяет недельные тренды, популярное и высокооценённую классику, убирает дубли, взрослый контент, ещё не вышедшие фильмы и позиции с недостаточным числом голосов. Точная официальная дата выхода сохраняется в каталоге и повторно проверяется перед рекомендацией, реакционными карточками, поиском, недельной подборкой и подсказкой следующей части серии. Если для фильма текущего года точная дата ещё не известна, Tonight не предлагает его до следующего обновления каталога. Вместе с русскими названиями, описаниями, жанрами, длительностью и рейтингами приложение кэширует постеры, фоны и безопасные ссылки на YouTube-трейлеры. Если интернет или TMDB временно недоступны, вечерний выбор продолжает работать по последнему локальному каталогу.

PowerShell:

```powershell
$env:TMDB_READ_TOKEN="ВАШ_READ_ACCESS_TOKEN"
.\.venv\Scripts\python.exe scripts\import_tmdb.py --list smart --pages 25 --images
```

Ручная команда нужна только для диагностики или немедленного принудительного обновления: в обычной работе достаточно `start.bat`. `--list smart --pages 25` собирает до 500 кандидатов из трёх источников. `--images` сохраняет постеры и фоны локально в `data/posters` и `data/backdrops`. Импорт можно запускать повторно: записи обновятся без дублей и без потери истории, оценок или списка «На потом».

Кнопка «Смотреть трейлер» появляется прямо в результатах поиска, на итоговом экране, после подтверждения выбора и в списке «На потом», если TMDB нашёл подходящий YouTube-трейлер. Приоритет: русский трейлер, затем официальный английский, затем другой доступный трейлер. Отсутствие трейлера не мешает выбору фильма.

This product uses the TMDB API but is not endorsed or certified by TMDB. Используйте developer API только для личного некоммерческого проекта и соблюдайте актуальные требования к атрибуции.

### Важно перед монетизацией

Бесплатный developer API TMDB и полученные через него изображения не лицензированы для коммерческого использования. Перед платным запуском нужно сделать одно из двух:

1. заключить письменное коммерческое соглашение с TMDB;
2. подключить другого поставщика метаданных и изображений с подходящей коммерческой лицензией.

Архитектура Tonight уже отделяет runtime от источника: приложение читает нормализованный локальный каталог и локальный media cache. Поэтому поставщика можно заменить, не переписывая рекомендатор и основной UX.

Официальные условия: [TMDB API FAQ](https://developer.themoviedb.org/docs/faq) и [API Terms of Use](https://www.themoviedb.org/api-terms-of-use).

## Где хранятся данные

- SQLite: `data/tonight.db`
- оригинальные fallback-обложки: `data/art/`
- локальные постеры: `data/posters/`
- локальные фоны: `data/backdrops/`
- резервные копии: `data/backups/`

Перезапуск сервера не удаляет пользователей, активный вечер, реакции, выборы, историю и оценки.

### Локальная сводка использования

На основном компьютере откройте «Проверить приложение» — блок «Как проходят
вечера» покажет долю вечеров с выбором, подтверждённые просмотры, перезапуски,
восстановления связи, нарушения стоп-жанров и типичное время до выбора. Сводка
считается из локальной базы и никуда не отправляется. Точное время для старых
вечеров не угадывается: оно начинает накапливаться с версии 1.6.4.

### Backup

В «Наш вкус» выберите «Скачать данные»: Tonight создаст свежую целостную копию SQLite и предложит сохранить файл `.db`. Его можно перенести в другую локальную копию Tonight и вернуть через «Восстановить из файла». Перед заменой приложение попросит подтверждение и автоматически сохранит страховочную копию текущих данных.

Дважды нажмите `backup.bat`, если нужна только локальная страховка. Он создаст целостную копию SQLite в `data/backups` с датой и временем — Tonight можно не останавливать. Также можно сделать backup из интерфейса API:

```powershell
Invoke-RestMethod -Method Post http://localhost:8000/api/backup
```

Файл экспорта содержит историю, оценки, настройки и локальный каталог базы, но не постеры и фоны. В переносимой версии они дополнятся из поставляемого локального каталога при следующем запуске.

## Технический запуск для команды Tonight

Этот раздел предназначен для авторизованной команды, которая обслуживает
Tonight. Для обычного использования выбирайте готовую переносимую версию.

После получения рабочей копии репозитория:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe launcher.py
```

Frontend не требует Node.js и отдельной сборки: сервер раздаёт готовые HTML, CSS и JavaScript. Это сделано намеренно, чтобы домашняя установка была максимально простой и надёжной.

Исходная версия содержит небольшой стартовый каталог и оригинальные fallback-
обложки. Полный каталог для обычного пользователя поставляется отдельно с
переносным релизом, а не хранится в истории Git.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

Проверяются fairness scoring, штраф за несогласие, жёсткие исключения, восстановление сессии, защита списка кандидатов и fallback при неправильном ответе Ollama.

Перед коммитом после заметного изменения также проверьте фронтенд:

```powershell
node --check frontend/app.js
```

## Что учитывает рекомендатор

1. Объединяет категорические стоп-жанры обоих людей.
2. Применяет наиболее строгие совместимые ограничения по длительности и эпохе.
3. Строит сигнал вкуса по сегодняшним реакциям и прошлым оценкам.
4. Считает прогноз отдельно для первого и второго зрителя.
5. Даёт большой вес меньшему прогнозу и штрафует сильное расхождение.
6. Добавляет профиль именно совместного просмотра, когда данных достаточно.
7. При доступной Ollama передаёт ей только уже отобранные локальные кандидаты с фактическими метаданными.

LLM возвращает только существующие ID и короткие объяснения. Она не ищет фильмы в интернете и не является источником фактов: для обновляемого каталога есть явный локальный импорт TMDB. Ответ проверяется Pydantic; неизвестный ID, timeout, отсутствие модели или неверный JSON автоматически возвращают детерминированный результат.

Все веса находятся в `backend/config.py` в словаре `SCORING`.

## Troubleshooting

### Второе устройство не может открыть адрес

- Оба компьютера должны быть в одной Wi‑Fi/LAN.
- Используйте LAN-адрес из окна Tonight, не `localhost`.
- Разрешите Python для частных сетей в Windows Firewall.
- Убедитесь, что роутер не включает AP/client isolation для гостевой сети.
- Проверьте с основного ПК: `http://localhost:8000/api/health`.

### Порт 8000 занят

Tonight автоматически попробует следующие свободные порты и напечатает фактический LAN URL. Если нужен фиксированный порт, создайте `.env` и задайте его явно:

```text
TONIGHT_PORT=8010
```

Перезапустите `start.bat` и используйте новый адрес.

### Ollama не видна

Проверьте локально на основном ПК:

```powershell
Invoke-RestMethod http://127.0.0.1:11434/api/tags
ollama list
```

Если Ollama выключена, ничего чинить срочно не нужно: Tonight продолжит работать без AI.

### Модель не установлена

```powershell
ollama pull qwen3:8b
```

Или укажите имя уже установленной модели в `.env`.

### Слишком мало рекомендаций

Если оба выбрали много стоп-жанров и короткую длительность, кандидатов может не остаться. Начните новый вечер с чуть более широкими рамками или импортируйте большой каталог.

## Приватность

Нет telemetry, trackers, рекламы, внешней авторизации и cloud AI. Runtime не отправляет вкусы, историю или локальную сводку использования никуда. Фоновое обновление передаёт TMDB только запросы публичного каталога по серверному токену; реакции, вкусы, история и оценки остаются локальными. Загруженные данные и изображения сохраняются на основном компьютере.

Простое описание всех данных находится в `PRIVACY.md`. В разделе «Наш вкус» на
основном компьютере можно экспортировать данные либо полностью удалить личную
историю, оценки, реакции, настройки, список «На потом» и локальные резервные
копии. Каталог фильмов, постеры и TMDB-настройка при этом сохраняются.
