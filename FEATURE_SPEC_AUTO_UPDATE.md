# Автообновление Tonight через GitHub Releases

## Контракт

- При запуске проверяется публичный Latest Release `vewi001/tonight`, без токена,
  cookie и личных данных. Повторная фоновая проверка не чаще раза в 6 часов.
- На основном компьютере доступны ручная проверка и добровольная кнопка
  «Скачать и обновить». Телефон не может устанавливать программу.
- Новее текущей должна быть стабильная версия `vX.Y.Z`; пакет называется строго
  `Tonight-update-X.Y.Z.zip`. Portable ZIP предназначен только для первой установки.
- Для загрузки обязательны размер и SHA-256 из GitHub API. URL ограничен этим
  репозиторием; разрешены только HTTPS-переходы на хосты загрузки GitHub.
- Загрузка потоковая в `Updates/`, частичный файл не считается готовым.
  Проверяются фактический размер, SHA-256, целостность ZIP и манифест Tonight.
- После скачивания отдельный обновитель перепроверяет пакет и подтверждает готовность.
  Tonight разрешает продолжение только после подтверждения; при ошибке запуска или
  таймауте обновитель отменяет установку, а Tonight продолжает работать.
  Затем обновитель ждёт завершения Tonight, создаёт backup
  и снимок программы, устанавливает пакет и запускает Tonight снова.
- `.env`, `.venv`, `data` и личные данные сохраняются. Каталог из пакета добавляет
  новые фильмы и недостающие медиа при запуске; пользовательский каталог не стирается.
- Сбой проверки или скачивания не мешает вечеру. Сбой установки возвращает прежние
  файлы программы. Откат схемы базы остаётся осознанным действием пользователя.
- Публикация новых релизов требует отдельного подтверждения владельца.

## Проверка

Тесты версий, недоверенных ответов/URL, размера, SHA-256, манифеста, частичной
загрузки, доступа с телефона, остановки/перезапуска, сохранения данных и отката.
После заметного среза: полный pytest, node --check frontend/app.js, git diff --check.
Для интерфейса и переносимого приложения — браузерная и Windows smoke-проверка.
После проверки обновляется пользовательская копия с сохранением .env/.venv/data.
Тестовый сервер всегда останавливается.

## Поставка

Текущая 1.6.4 обновляется вручную до первой версии с этим механизмом. В каждый
будущий опубликованный Release входят portable ZIP и update ZIP. Контрольная
сумма проверяет соответствие загруженному GitHub asset; это не независимая
цифровая подпись издателя.
