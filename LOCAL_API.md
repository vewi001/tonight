# Локальные инструменты Tonight

Интерфейс и API открываются по localhost, IP компьютера из приглашения или
имени этого компьютера. Не используйте произвольные DNS-псевдонимы и обратные
прокси: они не входят в проверенную модель локального доступа.

Запрос с Origin должен точно соответствовать адресу Tonight, включая схему и
порт. Чужой и `null` Origin отклоняются, CORS-разрешения не выдаются.
Неправильные и повторные Host также отклоняются. Проверки путей используют
ASGI scope, который использует маршрутизатор.

CLI/локальный инструмент без Origin может читать HTTP API на основном ПК.
Для POST/PUT/PATCH/DELETE передайте `Content-Type: application/json` с JSON,
либо `X-Tonight-Request: 1` для пустого или бинарного тела. Это явно обозначает
вызов инструмента и исключает простой браузерный запрос с чужой страницы.
Для действующих операций обновления также поддержан `X-Tonight-Update: 1`.
Эти заголовки не заменяют код вечера или ограничение основным компьютером.

WebSocket без Origin всегда требует `?code=XXXXXX`, в том числе на localhost.
Основной браузер передаёт свой Origin; телефон дополнительно передаёт код.
Loopback — ограничение местоположения, а `confirmed=true` — подтверждение
выбранной операции, но ни одно не даёт право чужой странице выполнить действие.

Предпочтения принимают 11 настроений интерфейса без повторов, длительность
1–1440 минут либо `null`, год 1888–2100 либо `null`. Числа должны быть целыми;
неизвестные поля (например, несуществующий max_year с противоречивым диапазоном)
отвергаются, а не игнорируются. Сочетания настроений разрешены, ограничения не
ослабляются при отсутствии подходящих фильмов.

## Стартовый каталог

Исходники содержат 72 записи. Для 20 из них сохранены реальные импортированные
подтверждения русского названия и кинопроката из поставки 1.13.0. Список и
SHA-256 исходной базы — в `backend/movies/starter_verified.py`; даты не выводятся
из года выпуска. Остальные 52 записи не получают придуманных подтверждений.
Эти 20 фильмов дают первоначальный выбор без интернета, Ollama и загрузок.
Повторный запуск дополняет только неизменённые стартовые записи без метаданных
подтверждения; ручные названия, импорт и явное снятие подтверждения сохраняются.
Полный каталог и реальные постеры можно получить через «Каталог и обновления».
Ошибка загрузки не удаляет исходный каталог; доступна повторная попытка.
