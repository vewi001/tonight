# Tonight 1.5 — переносимая папка и локальное обновление

## Цель

Это контракт первоначального локального обновителя. Для добровольного
скачивания обновлений начиная с 1.6.5 действует дополнительный контракт
[FEATURE_SPEC_AUTO_UPDATE.md](FEATURE_SPEC_AUTO_UPDATE.md).

Tonight можно запустить двойным нажатием из одной переносимой папки. Пользователю
не нужны терминал, виртуальное окружение или заранее установленный Python.

## Контракт

- Папка релиза содержит `Tonight.exe`, всё нужное для его работы и кнопку
  `Запустить Tonight`.
- Релиз также содержит отдельную папку `catalog/`: обезличенную базу фильмов,
  постеры и фоны. При первом запуске она добавляется в `data/`; в ней нет
  пользователей, истории, оценок, сессий или настроек.
- Данные пользователя всегда живут рядом с программой, в `data/`; `.env` также
  лежит рядом с программой. Они не входят в пакет релиза и не заменяются при
  обновлении.
- Обновление выбирает локальный файл `Tonight-update-<версия>.zip`. Приложение не
  скачивает обновления и не отправляет данные в интернет.
- Перед сменой файлов обновитель делает SQLite backup в `data/backups/`, а прежние
  файлы программы сохраняет в `rollback/previous/`.
- «Вернуть прошлую версию» возвращает предыдущие файлы программы и сохраняет
  текущие `data/` и `.env`. Если новая версия уже изменила структуру базы,
  автоматического отката базы нет: страховочная копия остаётся доступна для
  осознанного восстановления через интерфейс.
- Пакет обязан содержать манифест Tonight, формат `1`, номер версии и точный список
  файлов. Архивы с путями вне папки приложения либо с чужим манифестом отклоняются.
- Обновлять или откатывать можно только при остановленном Tonight.

## Не входит в этот релиз

- Фоновая загрузка или автоприменение обновлений.
- Учётная запись, облачное распространение, телеметрия.
- Гарантированный откат схемы SQLite после того, как пользователь продолжил
  пользоваться новой версией.

## Проверка

1. Созданный пакет проходит проверку манифеста и содержит полный локальный
   каталог с постерами и трейлерами.
2. Обновление сохраняет `.env`, `data/` и `.venv`, делает backup до записи новых
   файлов и оставляет снимок прежней программы.
3. Откат восстанавливает прежние файлы программы, не трогая пользовательские
   данные.
4. Переносимая сборка поднимает локальный сервер и отдаёт первый экран.
