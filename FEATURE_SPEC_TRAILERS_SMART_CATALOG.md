# Трейлеры и умный недельный каталог

## Цель

Tonight локально хранит официальный YouTube-трейлер и раз в календарную неделю пополняет каталог из нескольких официальных лент TMDB, не блокируя киновечер при отсутствии интернета.

## Контракты

- `movies.tmdb_id`: числовой идентификатор TMDB, nullable для полностью локальных записей.
- `movies.trailer_key`: только проверенный 11-символьный YouTube video id, иначе `NULL`.
- `movies.trailer_language`: `ru`, `en` или исходный язык выбранного ролика.
- `movies.trailer_checked_at`: время последней успешной проверки TMDB, включая результат «трейлера нет».
- `movies.catalog_sources`: JSON-массив источников `trending_week`, `popular`, `top_rated`.
- Выход фильма для UI содержит `trailer_url`: безопасный URL YouTube или `null`.
- Старые поля и существующие HTTP-маршруты не меняют смысл; изменение схемы и ответа аддитивное.

## Выбор трейлера

1. Русский YouTube-ролик типа `Trailer`.
2. Английский официальный YouTube-ролик типа `Trailer`.
3. Любой официальный YouTube `Trailer`, затем подходящий `Trailer`/`Teaser`.
4. Непроверенный site/key никогда не попадает во фронтенд.

## Состав каталога

- Источники: `/trending/movie/week`, `/movie/popular`, `/movie/top_rated`.
- Кандидаты объединяются round-robin, поэтому одна лента не вытесняет остальные.
- Дубли удаляются по TMDB ID до запросов деталей.
- Не импортируются adult-записи, будущие релизы, нулевой рейтинг и записи ниже минимального числа голосов.
- Трендовость отвечает только за обнаружение; итоговый рекомендатор продолжает учитывать вкусы пары, стоп-жанры, оценки и порядок франшиз.

## Совместимость и ошибки

- `initialize()` добавляет новые nullable-колонки без удаления данных.
- При совпадении starter и TMDB сохраняется starter ID, а связи истории, свайпов, watchlist и сессий не теряются.
- Импорт использует UPDATE/INSERT, а не SQLite `REPLACE`, чтобы не запускать каскадное удаление связей.
- Сбой TMDB записывает безопасный тип ошибки, оставляет локальный каталог рабочим и не меняет дату последнего успешного обновления.
- Ollama и YouTube Data API не требуются.

## Приёмка

- Кнопка `▶ Смотреть трейлер` видна в результате, подтверждении и «На потом» только при наличии `trailer_url` и открывает новую вкладку.
- Русский трейлер выигрывает у английского; английский официальный выигрывает у общего fallback.
- Один TMDB ID представлен одним фильмом, старые ссылки и пользовательские данные сохранены.
- Умный импорт использует все три источника, фильтрует недопустимые записи и скачивает метаданные/изображения/трейлеры локально.
- Официальная дата выхода хранится вместе с фильмом. До этой даты фильм не попадает в рекомендации, реакционные карточки, поиск, недельную подборку или подсказку следующей части серии. Для старых записей без точной даты безопасно доступны только фильмы прошлых лет.
- На главном экране показывается дата последнего успешного обновления каталога.
- Без TMDB приложение запускается, выбирает фильм, подтверждает просмотр и принимает обе оценки.
- Полный pytest, Python compile и JavaScript syntax check проходят.
