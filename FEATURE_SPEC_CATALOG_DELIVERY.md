# Надёжная доставка каталога — контракт 14.10.2026

Проверка сначала читает фиксированный публичный HTTPS URL
`https://raw.githubusercontent.com/vewi001/tonight/main/catalog/latest.json`.
Владелец подтвердил адрес и fallback только при HTTP 404. Никаких запросов
Releases API при успешном ответе, сетевой ошибке или повреждённом JSON.
Манифест не более 16 КиБ, без redirects, дублирующихся/неизвестных полей:
`format_version` (integer 1), `catalog_version`, `min_app_version`,
`archive_url`, `size_bytes`, `sha256`, `published_at` (UTC).
Версии — канонические X.Y.Z, размер — положительное целое в лимите пакета,
SHA-256 — 64 lowercase hex; URL точно соответствует repo/tag/имени ZIP.
Несовместимость проверяется до скачивания и повторно по содержимому ZIP.
Публичный файл подготавливается локально из проверенного готового архива;
новые релизы требуют отдельного подтверждения. Манифест содержит только уже
опубликованные метаданные пакета. TMDB-токен не нужен.

Загрузка использует credential-free HTTP client, identity encoding,
connect timeout 10 с, read timeout 30 с, максимум три попытки с задержками
1 и 2 с. Повторяются transport failures, 408/429/500/502/503/504 и короткий
ответ. Частичный обычный файл сохраняется в служебной папке CatalogDownloads,
привязанной к SHA-256/версии/размеру. В эту папку не попадают личные данные.
Под общей app/catalog OS-блокировкой повтор использует размер сохранённого
файла и Range. 206 допускает append только с точным Content-Range/total;
200 означает отсутствие поддержки Range и заменяет частичный файл полным
ответом. Полученные байты никогда не считаются доверенными до полного SHA.
Редиректы проверяются на каждом запросе, повтор начинает с исходного URL,
не с истёкшей подписанной CDN-ссылки. Ошибка протокола/размера/SHA/ZIP
не устанавливает пакет; повреждённый partial удаляется. Сетевой partial
сохраняется между попытками, ручными повторами и перезапуском Tonight.

Перед публикацией ZIP в staging: точный размер, SHA-256, структура пакета,
версия каталога, minimum app version (включая совпадение с index). Установщик
повторно проверяет архив; done только после transaction commit/recovery.
Проверенный ZIP может использоваться повторно после ошибки установки.
История/оценки/вкусы/списки/настройки/.env/.venv/data не изменяются при
проверке и неудачной загрузке. Нет автоматической установки/скачивания.

UI показывает полученные/полные МБ и процент, при обрыве — «Можно продолжить»
и кнопку «Продолжить загрузку». Сетевые ошибки не мешают локальному вечеру.
Ответы API не содержат путей, URL с секретами или исходных исключений.

Проверки: тесты до реализации, полный pytest/node --check/git diff --check
после срезов; реальные HTTP обрыв/Range/ошибки и браузер; собранный Tonight.exe
только в отдельной portable-копии с искусственными личными данными.
Синхронизация проверенных исходников сохраняет .env/.venv/data пользователя.
