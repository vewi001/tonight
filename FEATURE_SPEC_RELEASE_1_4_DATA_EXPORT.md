# Tonight — экспорт и восстановление локальных данных

## Зачем

Пара должна суметь сохранить свои локальные данные и перенести их в другую
копию Tonight без облачного аккаунта, ручной работы с папкой `data` или риска
случайно потерять текущую историю.

## Поведение

На экране «Наш вкус» доступны два самостоятельных действия.

1. «Скачать данные» создаёт свежую локальную копию базы и сразу предлагает
   скачать файл `.db`. Такая же копия остаётся в `data/backups/`.
2. «Восстановить из файла» принимает ранее скачанный файл `.db`. До замены
   данных приложение просит явное подтверждение и создаёт страховочную копию
   текущей базы.

После восстановления Tonight вновь инициализирует схему и дополняет локальный
каталог из поставляемой папки `catalog/`, если она есть. Это не удаляет
восстановленные историю, оценки, список «На потом» и настройки пары.

## Границы

- Экспорт и импорт выполняются только между браузером и локальным Tonight.
  Данные не отправляются разработчику или в облако.
- Файл должен быть SQLite-копией Tonight с целостной базой и обязательными
  таблицами. Пустые, повреждённые и слишком большие файлы отклоняются.
- Размер импортируемой базы ограничен 64 МБ. Постеры и фоны не включаются в
  экспорт: переносимая версия восстановит их из своего локального каталога.
- В этом сценарии нет удаления данных, автоматического восстановления и
  фонового импорта.

## Критерии готовности

- Скачанная копия может быть восстановлена через интерфейс только после
  подтверждения.
- До восстановления создана страховочная копия текущего состояния.
- Некорректный файл не становится доступной для восстановления копией и не
  меняет текущую базу.
- Полный набор тестов, проверка JavaScript и браузерная smoke-проверка
  проходят; после этого изменения синхронизированы в пользовательскую копию.
