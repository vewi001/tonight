# Единый шрифт и подтверждённые фильмы — 14.10.2026

Локальная правка без публикации GitHub и без синхронизации пользовательского
сетапа. Существующие изменения раскрытия описания сохраняются.

Шрифт: один поставляемый Noto Sans с кириллицей/латиницей, настоящий variable
weight, локальный /assets/fonts URL, SIL OFL рядом с файлом. Без local() и
внешних запросов во время работы. Button/input/select/textarea наследуют
гарнитуру; согласованные line-height и веса, без синтетического bold/italic.
Проверить 1280×900, 390×844, 844×390 и текст 200%, до/после, конец описания.

Доступный для выбора фильм должен иметь сохранённое подтверждённое русское
название, Released status и точную прошедшую кинотеатральную дату: TMDB
release_dates type 2/3, страна ISO alpha-2. Локализация берётся из translations
iso_639_1=ru (предпочтительно RU), либо original_title при original_language=ru.
Параметр language=ru-RU сам по себе не доказывает локализацию: возможен fallback.
Премьера type 1, digital/TV/physical, год, отсутствие или будущая дата не дают
права предлагать фильм. Кинотеатральный прокат в любой стране; ограничения
именно на российский прокат пользователь не задавал.

Добавляются nullable публичные movie metadata: russian_title,
theatrical_release_date, theatrical_release_type, theatrical_release_country,
release_status. Старые записи не получают выдуманных подтверждений и скрыты
до проверки источником. Старые данные/пакеты читаются; новые metadata в пакете
требуют min_app_version не ниже 1.6.8, чтобы старый читатель не принял новый
контракт. Никаких новых релизов или изменения опубликованного манифеста.

Единый predicate применяется в search/deck/recommendations/weekly/franchise
next/selection endpoints, включая сохранённые snapshots. Watchlist записи
не удаляются: неподтверждённый фильм скрыт из вариантов выбора, UI сообщает
количество скрытых записей и что сами записи сохранены. История/оценки
и текущие сохранённые записи сохраняются. Никакого live network при выборе.

Тесты: отсутствие ru translation, оригинальное/смешанное название, будущая
и неизвестная дата, только Released без theatrical, типы 1/4/5/6, валидные
2/3; все offer/selection пути, cached snapshots, сохранность личных таблиц,
миграция/пакет/перенос portable. Полный pytest/node --check/git diff --check.

Дополнения владельца: «Серии» поясняют, что это порядок всех подтверждённых
частей, а отметка просмотра определяется исключительно watch_history. Ранее
подпись ошибочно создавала впечатление списка только просмотренного.

«Будем смотреть» -> watching, без history/оценок и без опроса. Только явное
«Просмотр окончен» создаёт запись истории. Оценить можно отдельным действием
после просмотра или позже из карточки истории. Автоопрос при startup/reconnect/
событии completed удалён; оценка старого фильма не меняет текущий вечер.
