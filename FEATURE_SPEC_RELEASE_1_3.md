# Tonight 1.3 — спокойная связь и понятный выбор

## Для кого

Для двух зрителей, которые хотят выбрать фильм без технических терминов и без потери прогресса при кратком обрыве домашнего Wi-Fi.

## Поведение

### Связь

- `WinError 121` при чтении WebSocket считается обычным отключением клиента, а не аварией приложения.
- Сервер удаляет оборванное соединение из presence и продолжает работу.
- Браузер показывает «Связь пропала — восстанавливаем…», переподключается и получает актуальное состояние текущего вечера.
- После восстановления уже сохранённые реакции, результат и выбранный фильм остаются на месте.

### Объяснение рекомендации

- Каждый кандидат содержит ровно две короткие причины `plain_reasons`, построенные только из сохранённых реакций, выбранного настроения, ограничений и фактов о фильме.
- `stop_genres_respected` явно подтверждает прохождение жёсткого фильтра.
- Результат показывает причины и подтверждение стоп-жанров простыми словами.
- Если длительность или год были ослаблены, интерфейс говорит об этом отдельно.
- Технические детали скрыты в необязательном раскрываемом блоке; основной текст не использует `fairness`, `score`, `penalty` и «прогноз».

## Не входит

- Новая система аккаунтов или облачная синхронизация.
- Изменение формулы ранжирования и жёстких стоп-жанров.
- Новые внешние API.
- Изменение схемы SQLite.

## Приёмка

- Unit-тест отличает ожидаемый `WinError 121` от настоящей серверной ошибки.
- WebSocket можно закрыть и открыть повторно для той же сессии; сервер отвечает на `ping` и не теряет presence.
- Рекомендация всегда возвращает две простые причины и не содержит запрещённый жанр.
- Клиент после переподключения запрашивает актуальную сессию и сохраняет пользовательский экран.
- Полный pytest, Python compile, JavaScript syntax check и браузерный smoke проходят.
