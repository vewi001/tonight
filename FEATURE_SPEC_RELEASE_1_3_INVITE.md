# Tonight 1.3 — приглашение по QR и простой первый экран

## Для кого

Для зрителя, который запускает Tonight на компьютере, и второго зрителя, который подключается к текущему вечеру с телефона в той же домашней Wi-Fi-сети.

## Поведение

### Приглашение

- Сервер сообщает локальный сетевой адрес с фактически выбранным портом.
- На главном экране компьютера видны QR-код, короткий адрес и подсказка «Открой камерой телефона».
- QR ведёт на текущий Tonight с параметром `join=1`.
- Телефон по сетевому адресу сразу видит выбор пользователя и не проходит экран диагностики.
- При смене порта QR и адрес используют новый порт.

### Первый экран

- Основной список содержит только «Каталог готов», «Постеры загружены» и «Можно выбирать фильм».
- `Database`, `Ollama`, `AI model` и `Local network` находятся только в раскрываемом блоке «Если что-то не работает».
- Недоступная Ollama не мешает продолжить.

## Не входит

- Публикация сервера в интернет.
- Аккаунты, коды доступа и облачная синхронизация.
- Изменение рекомендаций, каталога или схемы SQLite.

## Приёмка

- API приглашения возвращает корректный LAN URL, активную сессию и QR в SVG.
- Порт, выбранный launcher, передаётся API приглашения.
- В браузере QR и адрес видны на главном экране компьютера.
- Сетевой адрес с `join=1` открывает выбор первого или второго зрителя без технического экрана.
- Полный pytest, Python compile, JavaScript syntax check и браузерный smoke проходят.
