# Приватность в локальной версии Tonight

Дата редакции: 22 октября 2026 года (Tonight 1.13.3).

## Коротко

Tonight 1.13.1 проверяет Host и источник HTTP/WebSocket-запросов.
Чужой веб-источник, включая другой локальный порт, не получает полномочия
основного компьютера. Для изменений требуются JSON или специальный заголовок
интерфейса; импорт резервной копии передаёт такой заголовок отдельно.
Параметр подтверждения в адресе не заменяет эту проверку. Сокет без Origin
требует действующий код даже на localhost. Доступ телефона по коду сохранён.
Правила для локальных инструментов описаны в [LOCAL_API.md](LOCAL_API.md).

История просмотров, оценки, реакции, настройки вечера и выводы о вкусах хранятся на вашем компьютере. Tonight не отправляет историю, оценки или профиль вкуса
разработчику и не использует внешнюю аналитику, рекламные трекеры или телеметрию.

## Что хранит Tonight

- два нейтральных профиля зрителей;
- выбранные настроения и стоп-жанры;
- реакции на карточки фильмов;
- историю просмотров и оценки; для одиночного вечера — выбранную компанию
  и ID единственного зрителя;
- список «На потом», вкусовые исключения и недельные подборки;
- персональные отметки «Уже смотрел» и «Не интересно» в Tonight Mode;
- историю предложенных фильмов за последние семь дней для разнообразия рекомендаций;
- локальные счётчики использования: завершённые выборы, время до выбора,
  перезапуски, восстановления связи и нарушения стоп-жанров;
- локальные резервные копии пользователя и страховочные копии перед
  восстановлением данных или установкой пакета каталога.

При ошибке загрузки из TMDB в `data/logs/tmdb-download.log` сохраняются время,
категория ошибки, названия типов исключений и счётчики обработанных фильмов.
Журнал не содержит токенов, адресов запросов, ответов TMDB или истории
просмотров и никуда автоматически не отправляется.

Эти данные находятся в папке `data/` рядом с программой. Скачанные экспорты
находятся там, куда их сохранил сам пользователь. Параметры, результаты и история
выдач Tonight Mode дополнительно сохраняются в текущей вкладке браузера отдельно
для каждого зрителя и очищаются при штатном удалении личных данных.

Tonight IQ, персональные рекомендации и Tonight Mode используют общие оценки
и реакции. Ранжирование выполняется локально и не обращается к AI API.
Отметка «Уже смотрел» сама по себе не создаёт оценку или совместный просмотр.
Сброс обучения сохраняет явные исключения; полное удаление личных данных
удаляет также новые отметки и историю предложений.

Сводка «Как проходят вечера» доступна только на основном компьютере. Она
содержит агрегированные числа, не записывает IP-адреса и сведения об устройстве
и не отправляется разработчику или сторонним сервисам.

## Когда используется интернет

При запуске и по кнопке проверки обновления Tonight обращается к публичным
релизам GitHub `vewi001/tonight`. GitHub получает обычные технические данные
соединения, включая IP-адрес, как при скачивании через браузер. Tonight не
добавляет к запросу историю, оценки, вкусы, TMDB-токен или личные файлы и не
записывает IP-адреса в журнал обновлений. Проверка не требует GitHub-аккаунта.
Скачивание начинается только по кнопке; пакеты хранятся локально в `Updates/`.
При обрыве сохраняется частичный файл публичного пакета, чтобы продолжить
загрузку после повторного запуска. Его имя связано с контрольной суммой;
личных данных и токенов в нём нет. Перед установкой проверяется весь файл.
Обновление программы не скачивает каталог и изображения повторно.

Отдельная проверка каталога сначала читает небольшой публичный манифест
`raw.githubusercontent.com/vewi001/tonight/main/catalog/latest.json`.
Только при отсутствии этого файла (HTTP 404) используется резервный GitHub
Releases API. При сетевой ошибке локальный каталог продолжает работать.
Частичные загрузки сохраняются в `CatalogDownloads/` и могут продолжиться;
они содержат только публичный пакет. Перед установкой проверяются полный
размер, SHA-256, структура ZIP и совместимость. Для проверки и
скачивания пакета каталога не нужен TMDB-токен или GitHub-аккаунт. К этим
запросам не добавляются личные данные, файлы или токены. Каталожный пакет
содержит карточки фильмов и изображения, а не пользовательскую базу SQLite;
скачивание и установка начинаются только по действию пользователя.
Временные каталожные файлы находятся в `CatalogDownloads/` и `CatalogUpdates/`.
Страховочные копии личной базы находятся в `data/backups/` и удаляются вместе
с другими локальными резервными копиями штатной командой удаления данных.

Если настроено обновление каталога, Tonight обращается к TMDB за публичными
сведениями о фильмах, постерами и трейлерами. TMDB получает обычные запросы
каталога и технические сетевые данные соединения, но Tonight не добавляет к ним
вашу историю, реакции, оценки или профиль вкуса.

Ollama, если она установлена, работает локально на основном компьютере. Tonight
не использует облачную AI-службу для обработки пользовательских вкусов.

## Экспорт

В разделе «Наш вкус» можно скачать копию данных SQLite. Такой файл содержит
личные данные Tonight. Пользователь сам выбирает, где его хранить и кому
передавать.

## Удаление

На основном компьютере в разделе «Наш вкус» можно выбрать «Удалить личные
данные». После ввода полной фразы подтверждения Tonight удалит историю, оценки,
реакции, настройки вечеров, список «На потом», выученный вкус и резервные копии
внутри папки Tonight.

Каталог фильмов, постеры, программа и TMDB-настройка останутся. Ранее скачанные
экспорты находятся вне Tonight, поэтому их нужно удалить вручную.

## Домашняя сеть

Другой зритель подключается только внутри домашней сети и вводит код текущего
вечера. Полное удаление разрешено только браузеру на основном компьютере.
Tonight не предназначен для публикации порта приложения в интернете.

## Перед коммерческим выпуском

Этот текст описывает фактическое поведение локальной версии. Перед продажей в
него нужно добавить юридическое имя владельца продукта, контакт для обращений,
применимую юрисдикцию и результаты юридической проверки. Коммерческое
использование данных TMDB требует отдельного разрешения или другого
лицензированного источника.


## Необязательное зеркало загрузок

В Tonight 1.8.0 общий публичный адрес зеркала читается из `app/mirror.json`
репозитория Tonight. Зеркало может быть включено владельцем. При его включении
публичные ZIP могут скачиваться с Яндекс Диска или настроенного HTTPS-хостинга.
Для Диска приложение передаёт официальному API только публичную ссылку на
папку и путь к публичному архиву. Пароль, OAuth-токен, история, оценки и
настройки вкуса к запросу не добавляются. Временная ссылка на файл
получается заново; при недоступности зеркала используется GitHub.
Проверки размера и контрольной суммы остаются прежними.

## Добавление фильмов с главной страницы

С Tonight 1.9.0 кнопка «Добавить фильмы и постеры» запрашивает новые карточки
у `api.themoviedb.org` и изображения у `image.tmdb.org`. По решению владельца
в сборку и исходную поставку включён отдельный ключ приложения Tonight.
В исходниках он опубликован с разрешения владельца в `app/tmdb-public.json`. Это ключ приложения,
а не доступ к личному профилю зрителя. Свой ключ из локального `.env` может
заменить его. Ключ не возвращается браузеру через API, но поставляемую с EXE
учётную информацию следует считать извлекаемой из приложения.

TMDB получает ключ приложения, IP компьютера и запросы публичных карточек.
История просмотров, оценки, личные правки и вкусы не отправляются. Телефон
отправляет команду компьютеру с Tonight по локальной сети, а не загружает
постеры в свою память. Доступ с телефона требует кода текущего вечера.
Добавленные карточки и постеры сохраняются на компьютере; резервная копия
базы создаётся перед загрузкой. Отсутствующий постер не удаляет карточку.


## Старые совместные подборы по приглашениям

Отдельный режим комнат удалён. Новые комнаты и приглашения не создаются,
старые ссылки открывают главную с пояснением. Ранее сохранённые записи в базе
и списки в браузере остаются на месте; обновление их не удаляет и не изменяет.
Они не используются как активный вечер и не дают доступ к профилям по старому приглашению.

Совместный подбор по знакомым фильмам сохраняет оценки и предпочтения в профилях
на компьютере Tonight. Подключение телефона по адресу, QR и коду вечера сохранено.
