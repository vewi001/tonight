# Tonight 1.4 — «Не предлагать похожее»

## Для кого

Для любого из двух зрителей, когда выбранный фильм не подходит не только сегодня, а похожие варианты тоже нежелательны в будущих рекомендациях.

## Поведение

- На экране финального выбора есть отдельное раскрываемое действие «Не предлагать похожее».
- До подтверждения интерфейс показывает, какие признаки ослабнут: сочетание жанров, настроение и франшиза.
- Подтверждение сохраняет персональный сигнал и возвращает пару к списку рекомендаций.
- Сигнал сильнее обычной реакции `dislike`, но только снижает похожие фильмы, не запрещая жанр целиком.
- В разделе «Наш вкус» текущий пользователь видит свои сильные отказы и может отменить любой из них.
- После отмены влияние сразу исчезает из следующих расчётов.

## Данные и совместимость

- Сигналы хранятся локально в новой таблице `avoid_similar`.
- Существующие история, оценки, сессии и каталог не изменяются.
- Внешние API и Ollama не требуются.

## Не входит

- Автоматическая блокировка целого жанра.
- Общее правило сразу для обоих пользователей.
- Удаление уже сохранённой истории или оценок.

## Приёмка

- Добавление, список и отмена сигнала защищены тестами.
- Точная или близкая рекомендация заметно опускается после сильного отказа.
- Другие фильмы того же жанра остаются среди кандидатов.
- API сильного отказа отклоняет фильм и возвращает сессию к рекомендациям.
- UI показывает признаки до подтверждения и позволяет отменить сигнал в «Наш вкус».
- Полный pytest, Python compile, JavaScript syntax check и браузерный smoke проходят.
