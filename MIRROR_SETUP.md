# Зеркало Tonight на Яндекс Диске

S3 и отдельный сервер не нужны. Для зеркала подходит публичная папка на
Яндекс Диске. Tonight 1.8.0 умеет получать ссылку на конкретный ZIP через
официальный API Диска, без пароля и OAuth-токена пользователя.

## Что сделать владельцу

1. Откройте подготовленную папку `Tonight-mirror` в «Загрузках».
2. Загрузите её **целиком** на Яндекс Диск, сохранив вложенные папки.
   ZIP-файлы не распаковывайте и не переименовывайте.
3. У самой папки `Tonight-mirror` выберите «Поделиться» и включите доступ
   по ссылке. Нужна ссылка на папку, а не на один архив.
4. Пришлите публичную ссылку в чат. После проверки наличия файлов её можно
   подключить для всех пользователей Tonight через файл `app/mirror.json`.

В папке только готовые публичные архивы и их контрольные суммы. Не добавляйте
сюда папку установленного Tonight, `data`, `.env`, историю или резервные копии.

Скорость и доступность Диска зависят от самого сервиса. При недоступности
зеркала Tonight возвращается к GitHub. Скачанный файл всегда проверяется по
размеру и SHA-256 из описания на GitHub; зеркало не меняет ожидаемую версию.

Папка должна иметь такую структуру:

```text
Tonight-mirror/
  v1.12.2/
    Tonight-update-1.12.2.zip
    Tonight-portable-1.12.2.zip
    SHA256SUMS.txt
  v1.12.1/
    Tonight-update-1.12.1.zip
    Tonight-portable-1.12.1.zip
    SHA256SUMS.txt
  v1.12.0/
    Tonight-update-1.12.0.zip
    Tonight-portable-1.12.0.zip
    SHA256SUMS.txt
  v1.11.4/
    Tonight-update-1.11.4.zip
    Tonight-portable-1.11.4.zip
    SHA256SUMS.txt
  catalog-v1.1.0/
    Tonight-catalog-1.1.0.zip
    Tonight-catalog-1.0.0-to-1.1.0.zip
  catalog-v1.2.0/
    Tonight-catalog-1.2.0.zip
    Tonight-catalog-1.1.0-to-1.2.0.zip
    Tonight-catalog-1.0.0-to-1.2.0.zip
  SHA256SUMS.txt
  README.txt
```

## Подключение в приложении

Публичное зеркало подключено; исходные четыре архива проверены по размеру и
SHA-256. При каждом выпуске добавляйте новую папку релиза в ту же публичную
папку Диска. Пока новых архивов там нет, Tonight берёт их с GitHub:

```json
{"format_version":1,"kind":"yandex-disk","url":"https://disk.yandex.ru/d/fA042rBy8NJ1aA"}
```

При замене зеркала после проверки папки в `app/mirror.json` указывается
`kind: "yandex-disk"` и поле `url` с новой публичной ссылкой. Для отключения
используйте `{"format_version":1,"kind":"none"}`. Tonight перечитывает этот небольшой
файл при фоновой проверке обновлений; перезапуск позволяет получить настройку
сразу. Пересобирать EXE ради замены ссылки не требуется.

Для проверки только на своём компьютере можно добавить в локальный `.env`
строку `TONIGHT_YANDEX_MIRROR=` с публичной ссылкой и перезапустить Tonight.
Эта настройка имеет приоритет над общим зеркалом. Пароль от Яндекса не нужен.

## Как выпускаются изменения каталога

Полный пакет по-прежнему описывается в `catalog/latest.json` и подходит старым
версиям Tonight. Пакеты изменений перечисляются отдельно в
`catalog/deltas.json`. В них указаны точная исходная версия, конечная версия,
минимальная версия приложения, размер и SHA-256.

Tonight выбирает изменения только для совпадающей исходной версии и когда
пакет меньше полного. При неизвестной или другой версии остаётся полный
пакет. Перед установкой исходная версия проверяется повторно внутри
транзакции. Личные данные, правки и уже имеющиеся изображения сохраняются.
Пакет не удаляет фильмы из истории. Для недостающих старых изображений можно
явно выбрать полный пакет. Старая копия без версии может потребовать одного
полного обновления; версия не угадывается по количеству фильмов.

Подготовка из двух уже проверенных публичных архивов:

```powershell
.venv/Scripts/python.exe scripts/build_catalog_delta.py --base BASE.zip --target TARGET.zip --output DELTA.zip --index-output deltas.json --published-at UTC_DATE
```

Имена в опубликованном релизе: `Tonight-catalog-A.B.C-to-X.Y.Z.zip` в
релизе `catalog-vX.Y.Z`. Сначала публикуется архив и проверяются его размер
и SHA-256, затем обновляется `catalog/deltas.json`. Релиз каталога не должен
становиться Latest приложения.

Источник о получении ссылки на скачивание публичного ресурса:
[документация Яндекса](https://yandex.cloud/ru/docs/datasphere/operations/data/connect-to-ya-disk).
