# Зеркало загрузок Tonight

Публичная папка [Tonight на Яндекс Диске](https://disk.yandex.ru/d/fA042rBy8NJ1aA)
служит дополнительным источником архивов. Приложение получает ссылку на файл
через API Диска без входа пользователя. Если зеркало недоступно, загрузка
возвращается к GitHub. Размер и SHA-256 проверяются по манифесту релиза.

## Структура папки

Сохраняйте имена архивов и папки версий. ZIP-файлы распаковывать не нужно.

```text
Tonight-mirror/
  v1.13.2/
    Tonight-portable-1.13.2.zip
    Tonight-update-1.13.2.zip
    SHA256SUMS.txt
  catalog-v1.2.0/
    Tonight-catalog-1.2.0.zip
    Tonight-catalog-1.1.0-to-1.2.0.zip
    Tonight-catalog-1.0.0-to-1.2.0.zip
```

Добавляйте только публичные архивы релиза и их контрольные суммы. Личные
`data/`, `.env`, историю и резервные копии в зеркало не включайте.
При обновлении сохраняйте пакеты, необходимые старым установкам и откату.

Для подготовки папки из проверенных файлов можно использовать:

```powershell
.\.venv\Scripts\python.exe scripts\prepare_download_mirror.py --inventory inventory.json --output Tonight-mirror
```

`inventory.json` содержит список объектов с полями `local_path`, `url`, `size`
и `sha256`. Скрипт сверяет файлы с этими значениями и создаёт папку для загрузки.
Публикация на Диске выполняется отдельно.

## Подключение зеркала

Загрузите папку на Диск и включите доступ по ссылке к самой папке.
В `app/mirror.json` укажите её публичный адрес:

```json
{"format_version":1,"kind":"yandex-disk","url":"https://disk.yandex.ru/d/fA042rBy8NJ1aA"}
```

Приложение перечитывает настройку при фоновой проверке обновлений.
Для отключения зеркала используйте `{"format_version":1,"kind":"none"}`.
Для локальной проверки задайте `TONIGHT_YANDEX_MIRROR` в `.env` и перезапустите
Tonight; локальная настройка имеет приоритет над общей.

## Пакеты изменений каталога

Полный пакет описан в `catalog/latest.json`, пакеты изменений —
в `catalog/deltas.json`. Для каждого указаны исходная и конечная версии,
минимальная версия приложения, размер и SHA-256.

Tonight выбирает пакет изменений только для совпадающей исходной версии
и когда он меньше полного. При неизвестной версии используется полный пакет.
История, оценки, личные правки и существующие изображения сохраняются.
Для восстановления недостающих изображений можно явно загрузить полный пакет.

Подготовка пакета из двух публичных архивов:

```powershell
.\.venv\Scripts\python.exe scripts\build_catalog_delta.py --base BASE.zip --target TARGET.zip --output DELTA.zip --index-output deltas.json --published-at UTC_DATE
```

Опубликуйте `Tonight-catalog-A.B.C-to-X.Y.Z.zip` в релизе `catalog-vX.Y.Z`,
проверьте размер и SHA-256, затем обновите `catalog/deltas.json`.
Релиз каталога не должен становиться Latest приложения.
