# Ревизия интерфейса Tonight 1.11.2

## Устройство и границы изменений

Интерфейс остаётся единым приложением `frontend/app.js` с общей оболочкой,
рендерерами существующих экранов и обработчиками действий. FastAPI обслуживает
его из `frontend`; portable EXE включает те же файлы. Общие стили сохранены,
согласованные правила размеров и иерархии вынесены в `frontend/clarity.css`.

SQLite хранит каталог, сессии, историю, оценки, реакции и списки. Действия
Кино-Tinder и полноценная отмена продолжают выполняться существующими серверными
транзакциями. Колоды и текущие настройки подбора восстанавливаются из
`sessionStorage`; флажок добавления интересных фильмов в список хранится в
`localStorage` отдельно для каждого зрителя. Настройка относится к браузеру,
а не синхронизируется между устройствами. Серверные алгоритмы Tonight IQ,
рекомендаций и правила доступа устройств не изменены.

## Назначение экранов и основное действие

| Раздел | Основное действие и упрощение |
| --- | --- |
| Выбор зрителя | Два профиля; подключение телефона раскрывается отдельно. Загрузка каталога больше не предшествует выбору. |
| Главная | «Подобрать фильм»; рулетка, Кино-Tinder и совместный выбор представлены спокойнее. Загрузка каталога появляется здесь при работе или ошибке. |
| Tonight Mode | Существующие четыре шага и выбор фильма. Убраны повторные названия шагов и очевидные инструкции. Второстепенные реакции доступны через «Другие действия». |
| Кино-Tinder | Фильм, три подписанных действия и компактная отмена рядом. Настройка списка и новая сессия находятся в меню; новая сессия также доступна при исчерпании колоды. |
| Кинорулетка | Получение одного фильма. После результата настройки сворачиваются; все ограничения и режимы остаются доступны. |
| Персональный подбор, неделя, поиск | Общие карточки, компактные настоящие постеры и прежний переход к выбору на вечер. |
| Совместный выбор | Сохраняются настроение, ограничения, реакции обоих и результат. Мобильные подсказки клавиш скрыты. Над карточкой явно объясняется: уже смотрели — оцените впечатление, не смотрели — нажмите «Не смотрел(а)»; желание посмотреть здесь не оценивается. |
| Подробности и выбор | Явное раскрытие, возврат, полное описание; постер не вытесняет действия. |
| История, оценки, «На потом» | Прежние действия, поиск, фильтры и редактирование оценок; компактные общие карточки. |
| Вкус и настройки | Управление обучением, резервными копиями и личными данными раскрывается по понятным подписям. Последствия удаления и сброса сохранены. |
| Каталог и обновления | Отдельный раздел в «Разделах». Телефон сохраняет разрешённое пополнение каталога; установка пакетов приложения и служебное управление доступны только основному компьютеру. |
| Диагностика | Доступна из меню и каталога. Проверка, локальная сводка и технический журнал остаются доступны. |

## Общие исправления

- Навигация собрана в подписанное меню на компьютере и телефоне; текущий раздел обозначен для средств доступности.
- Общая иерархия заголовков, отступов, кнопок и карточек. Панель действий Кино-Tinder находится в потоке и не перекрывает содержимое.
- В 1.11.1 устранён крайний случай 320-пиксельного окна с обычными полосами прокрутки: ширина `body` теперь совпадает с реально доступной областью корневого элемента. Подписи действий не разрываются внутри слов.
- Отсутствующие постеры заменяются нейтральной компактной заглушкой. Ошибка загрузки имеет честную подпись. Каталог передаёт наличие настоящего постера и для обычных карточек.
- Сохраняются видимый фокус, доступные названия, текст важных действий, уменьшенная анимация и настольные сочетания клавиш.
- Подробности Кино-Tinder открываются отдельной кнопкой или Enter; обработчик свайпа не захватывает кнопки. Сенсорный свайп начинается на постере, текстовая область остаётся для прокрутки.
- Для HTTP по локальной сети сохранён запасной способ генерации идентификаторов запросов через `crypto.getRandomValues`. Повтор после потери ответа использует прежний идентификатор.
- Открытые меню и раскрытия сохраняются при фоновой перерисовке; одинаковые меню разных фильмов различаются по идентификатору фильма.

## Проверки

- Полный набор: **584 теста прошли**. После окончательных правок раскрытий и рулетки дополнительно прошли 22 профильные проверки и 16 проверок интерфейса, мобильного поведения и обновлений. Проверка синтаксиса JavaScript и `git diff --check` успешны.
- Браузер: размеры **320×568**, **390×844** и **1440×900**; выбор зрителя, главная, Tonight Mode, подробности и возврат, одиночный выбор/завершение без оценки, история, список, вкус, неделя, серии, поиск, диагностика, каталог, Кино-Tinder и рулетка.
- В проверенных разделах ширина содержимого не превышает ширину экрана. В собранном EXE на 320×568 все три действия Кино-Tinder и отмена доступны в видимой области.
- Проверены интерес, сохранение в список и отмена, сохранение настройки после перезагрузки, отдельное значение второго зрителя, открытие подробностей мышью и Enter, возврат по Escape. Для HTTP использован адрес локальной сети; действие и отмена отработали в браузере с кодом подключения.
- Отсутствующие постеры проверены на изолированном каталоге без медиа; длинные названия взяты из настоящего каталога. Ошибки запросов, потеря ответа, повтор, пустые выборки, отсутствующие метаданные и уменьшенная анимация также покрыты существующими автоматическими проверками.
- Все файлы `frontend`, извлечённые из итогового EXE, побайтно совпадают с исходниками. Проверены оба ZIP и разрешённый состав файлов. В поставляемом каталоге 671 запись; таблицы пользователей, истории, предпочтений и действий пусты.
- Отдельная копия существующей установки **1.7.1 → 1.11.2** обновлена настоящим отдельным обновителем. Проверено сохранение всех строк 17 существовавших таблиц, резервная копия, откат и соответствие ресурсов, выдаваемых новым EXE. Исходная установка не изменялась.

Это проверка размеров браузера и HTTP-доступа с компьютера. Физические телефоны,
их экранная клавиатура, жесты ОС, Safari/iOS и Android Chrome не проверялись.
Снимки основных экранов сохранены отдельно в локальном отчёте задачи.

## Обновление

Закройте Tonight. Запустите «Обновить Tonight.exe» из существующей папки и
выберите `Tonight-update-1.11.2.zip`. Сохраните `data`, `.env` и `.venv`.
Полный `Tonight-portable-1.11.2.zip` предназначен для новой установки.
Для встроенного обновления откройте «Разделы → Каталог и обновления» на
основном компьютере и проверьте обновления приложения.
