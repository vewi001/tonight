# Tonight 2.0 — полное удаление личных данных

## Цель

Дать владельцу основного компьютера понятный способ удалить накопленные Tonight
личные данные перед передачей устройства, прекращением использования или по
собственному решению.

## Контракт

- Действие доступно только из браузера на основном компьютере.
- Перед удалением нужно ввести точную фразу `УДАЛИТЬ ВСЕ ДАННЫЕ`.
- Удаляются вечера, реакции, оценки, история просмотров, список «На потом»,
  недельные подборки, вкусовые исключения и локальные резервные копии Tonight.
- Сохраняются каталог фильмов, постеры, фоны, трейлеры, программа, `.env`,
  TMDB-настройка и нейтральные профили зрителей.
- После удаления SQLite очищает журнал и свободные страницы, а подключённые
  телефоны получают событие сброса и закрывают старый вечер.
- Если локальную резервную копию удалить невозможно, основная база не очищается
  и пользователь получает понятную ошибку.
- Скачанные пользователем файлы экспорта за пределами папки Tonight приложение
  удалить не может; интерфейс предупреждает об этом заранее.

## Не входит в срез

- Удаление каталога и медиафайлов.
- Удаление или отзыв TMDB-токена.
- Поиск экспортов в произвольных папках компьютера.
- Облачное удаление: текущая версия не отправляет личные данные в облако.

## Проверка

1. Интеграционный тест заполняет каждую пользовательскую таблицу, удаляет данные
   и подтверждает, что каталог и служебные настройки сохранились.
2. Повторное удаление безопасно и оставляет базу целостной.
3. Удалённый клиент домашней сети и неверная фраза получают отказ без изменений.
4. Файлы из `data/backups` исчезают, внешние файлы не затрагиваются.
5. Браузерная smoke-проверка открывает диалог, проверяет предупреждение и
   заблокированную финальную кнопку, но не удаляет реальные данные.
